# Jzzhu and Numbers

Codeforces 449D, difficulty 2400. [Archived problem](https://codeforces.com/problemset/problem/449/D)

**Accepted** on November 4, 2026 (Asia/Kolkata). [Judge record](https://codeforces.com/contest/449/submission/397270120)

## Approach

Superset sums over bitmasks and inclusion-exclusion. O(n + B·2^B) time and O(n + 2^B) space.

## Verification

132 exhaustive subset comparisons. Run `python3 test_solution.py` for the checked-in examples and edge cases.
