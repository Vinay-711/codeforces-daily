## Approach

The solution iterates through the input string, converts each character to lowercase, checks if it is a vowel (a, o, y, e, u, i), and if it is not, appends a '.' followed by the character to a StringBuilder. Time complexity is O(N) and space complexity is O(N) where N is the length of the input string.
