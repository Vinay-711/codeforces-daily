## Approach

The problem asks to check if the sum of all force vectors (x, y, z) equals (0, 0, 0). We iterate through the n input vectors, maintaining running sums for x, y, and z coordinates. If all three sums are zero at the end, the body is in equilibrium. Time complexity is O(n) and space complexity is O(1).
