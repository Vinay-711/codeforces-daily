## Approach

The solution counts the occurrences of digits '4' and '7' in the input string. It then checks if the resulting count is itself a lucky number (contains only '4' and '7'). Time complexity is O(D) where D is the number of digits (max 18), and space complexity is O(D) to store the input string.
